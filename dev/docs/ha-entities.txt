# EXCEPTION MESURÉE — Illuminance : son entity_id ne suit pas le préfixe d'appareil. Il est
# resté `sensor.esp32_weather_illuminance`, hérité du nœud ESPHome précédent que HA a réutilisé.

# (constante EXCEPTIONS) : c'est une mesure, pas une coquille. À savoir avant de nettoyer
# l'ancienne entrée d'appareil dans HA, qui peut emporter cet entity_id avec elle.
#
# Rafraîchir après tout renommage, changement de nom d'appareil ou nouvelle entité :
#   1. Home Assistant → Outils de développement → États, filtrer « vevor », coller les
#      couples nom / entity_id ci-dessous (un par domaine : binary_sensor, sensor, …) ;
#   2. .venv/bin/python dev/tools/check_ha_card.py   → doit rendre 0 échec.
